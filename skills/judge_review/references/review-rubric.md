# judge_review · 评审执行完整规范（L3 参考，judge 节点执行依据）

SKILL.md 正文的精读版本。评审节点（judge）执行时若有歧义，以本文件为准。

## 评审架构（分节并行 + 全局 + 确定性证据）

- **局部评审**：正文按一级节（##）切分，每节一次评审（ThreadPool 并行），输入从全文降到每节约 2800 字（实际切片 1500-2800）；对 4 维打分。
- **全局评审**：一次评完 5 维（只喂节标题 + 统计 + 首尾抽样各 300 字）。
- **确定性证据信号**：引用精确映射 + bge-m3 余弦，先于 LLM 标出低支持/无锚句子，注入局部评审作为硬信号（从严扣分），不把证据支持度完全交给 LLM 裁量。
- **从严打分**：阈值 `JUDGE_PASS_THRESHOLD`（默认 8.5），宁严勿宽；`< 阈值` 触发自动重写（最多 3 轮），通过时择优保留历史最佳稿。

## 局部评审 4 维（各 1-10）

1. 内容深度——是否深入对比不同方法的原理与优缺点
2. 逻辑严谨性——论证是否清晰有层次、不自相矛盾
3. 证据忠实度——每个论断引用的 [N] 是否真被该节引用论文支持；核心事实（方法/机制/结论/数字/年份）与引用论文明显不符、夸大、无中生有必须扣分
4. 覆盖度——是否覆盖应有的子方向（缺失报 coverage_gap）

## 全局评审 5 维（各 1-10）

1. 结构完整性——引言/各节/结论/参考文献齐全，节序合理
2. 学术规范性——章节格式统一、术语准确、引用编号连续可查（断档/格式混用扣分）
3. 即时约束遵守度——严格遵守用户本次明确提出的约束（无额外约束给满分）
4. 记忆偏好遵守度——遵守记忆档案长期偏好（空则给满分）
5. 篇幅遵守度——正文 vs 预算：≤预算 10 分；预算~1.25×预算 9 分；1.25×~1.5× 3-6 分；>1.5× 1-3 分

## 确定性证据两档（不要同等对待）

- **确定性问题**（必须扣分并列入 issues）：引用池中不存在的编号 / 陈述事实却无引用 / NLI 判定论断与引用论文**矛盾**
- **辅助提示 weak_match**（须法官判断后再决定是否扣分）：仅相似度边距偏低，通用背景句常误报

## 引用锚点口径（v1.2.13 硬约束，评审与切句共同依据）

- **一句号一句 = 对一篇论文的引用**：以句号（。！？）结尾的完整论断句，句尾有 [N] 即视为
  **已锚定**；句内以逗号/分号连接的子句（如「XX提出了XX，解决了XX，指标XX[12]。」）
  **不要求各自标注**，不得据此报 no_anchor/no_citation。
- 确定性切句只按句号级分隔（`。！？.!?` + 换行），**分号（；）不是句子边界**。
- 只有整个句号句完全无 [N] 且像需要出处的事实陈述时才报 no_citation。

## 输出契约

- 局部：`{"内容深度","逻辑严谨性","证据忠实度","coverage_ok","issues":[{type,claim,problem,fix}]}`
- 全局：`{"结构完整性","学术规范性","即时约束遵守度","记忆偏好遵守度","篇幅遵守度","issues":[...]}`
- issues.type ∈ citation_mismatch|no_anchor|evidence_insufficient|faithfulness|logic_gap|coverage_gap|style
- 即使没问题也给出 0-2 条改进项；有问题必须列出。

## 缺陷分流（route_after_judge · 已简化为只标注不返工）

- **单次评审直接交付**：`judge → save`，无论通过与否（用户决策 2026-10：重写/补检太慢，
  去掉多轮重写与 re_search）。评审报告列出全部缺陷与低置信内容清单（含原因），交用户审核。
- 证据类缺陷（evidence_insufficient|no_anchor|faithfulness 合计占比）与写作类缺陷
  （结构/深度/逻辑）**只计入报告**，不触发补检索、不触发重写——"每个大纲只检索一轮"。
- 确定性证据检查（逐句 verdict + NLI + 余弦）是评审的硬信号：低置信清单每条带
  所属节/原文句子/问题类型/原因，供用户逐条人工核实。

## 聚合与兜底

- 聚合 8 维：全局 5 维直接取，局部 4 维（内容深度/逻辑严谨性/证据忠实度/覆盖度）取各节均值。
- 缺失 ≥2 维 → fail-closed（0 分，判不通过；单次评审不重写）；缺失 1 维 → 用其余 7 维重算。
- 引用真实性（确定性校验）：`cite["total_refs"] >= 3 且 rate < 0.6` → fail-closed 判不通过。
- 迭代快照写入 state.iteration_log（round/total/dims/citation_rate/issues_dist），供 keep-best 与复盘。
